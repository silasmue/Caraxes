# A recorded AUX transcript: every NV0073_CTRL_CMD_DP_AUXCH_CTRL the stock NVIDIA
# 610.57.04 guest driver (nvidia-modeset's DP library, loaded with nvidia-drm modeset=1
# fbdev=0) sent to the Caraxes device on 2026-09-23, run b3 of
# caraxes/runs/display-ab-2026-09-23 (docs/caraxes/display-ab.md), in order, with the
# replies the device gave, plus the link training the library requested through DP_CTRL
# (`! train`, `! drop-link`). The sink is SinkProfile::dp14_hbr3_x4_dsc with the EDID in
# caraxes-dp-monitor.edid.bin (the bytes the guest exposed in
# /sys/class/drm/card0-DP-1/edid). Extracted from the device trace by
# caraxes/runs/display-ab-2026-09-23/transcript.py. It replaces the hand-written
# nvidia-sst-discovery.txt. Differences from what that file assumed: the real library
# reads 0x00E first and then the extended caps at 0x2200 (DPCD 1.4), reads and clears the
# DP-tunneling registers 0xE000D and 0xE0030, sends no DDC ping, probes DisplayID at 0x52
# twenty times (segment pointer write to 0x30, then I2C NACK at 0x52) before the EDID at
# 0x50, reads both EDID blocks with 16-byte MOT reads after one offset write per block,
# trains HBR3 x4 through DP_CTRL rather than over AUX, and ends detection with SET_POWER D3
# (0x600 = 2) and a DP_CTRL with lane count 0.
