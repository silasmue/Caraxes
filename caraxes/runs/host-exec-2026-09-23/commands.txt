# Commands of the host-exec run, 2026-09-23 (Europe/Berlin)

Build (uid 1000):
  rustc -O --edition 2021 caraxes/tools/host-exec.rs -o target/host-exec

Run (via the wrapper, which captures host-before/after and the journal):
  caraxes/tools/host-exec.sh --max-stage F

Equivalent direct invocation:
  sudo -n target/host-exec run --go --max-stage F

Stages: A reserve+map VRAM, B pin sysmem + read IOVA (admin) + build the GMMU v2
page table in VRAM, C VA space + channel + DMA_SET_PAGE_DIRECTORY (admin) + schedule
+ token + doorbell, D doorbell semaphore release + CE copy, E non-stall OS event,
F GR channel + TURING_COMPUTE_A + GPU_PROMOTE_CTX (admin). Default max stage is D.

CAP_SYS_ADMIN is raised only around GET_SURFACE_PHYS_ATTR, DMA_SET_PAGE_DIRECTORY and
GPU_PROMOTE_CTX (5 windows in an A-F run). Everything else runs as uid 1000. Every RM
object is freed on every exit path (SIGINT/SIGTERM close the client fd). No register
access, no host module change, no passthrough.
