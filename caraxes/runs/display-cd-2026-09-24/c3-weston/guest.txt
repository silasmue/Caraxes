Usage: weston-presentation-shm [mode] [options]
where 'mode' is one of
  -f		run in feedback mode (default)
  -i		run in feedback-idle mode; sleep 1s between frames
  -p		run in low-latency presentation mode
and 'options' may include
  -d msecs	emulate the time used for rendering by a delay 
		of the given milliseconds before commit

Printed timing statistics, depending on mode:
  commit sequence number
  f2c: time from frame callback timestamp to commit
  c2p: time from commit to presentation
  f2p: time from frame callback timestamp to presentation
  p2p: time from previous presentation to this one
  t2p: time from target timestamp to presentation
  seq: MSC
