# SST discovery, EDID read, link training and teardown against the default sink
# (SinkProfile::dp11a_hbr_x4, EdidSpec::first_monitor). The request order follows the
# NVIDIA 610.57.04 DP library as read in source (dp_sst_edid.cpp sstDDCPing and
# readNextBlock with a 16-byte transaction size, dp_evoadapter.cpp EvoAuxBus::transaction);
# it is NOT a capture from a guest. Replace it with a recorded trace once gate D2 exists.
# The DPCD replies are derived by hand from the DP 1.1a register definitions; the EDID
# bytes were checked with edid-decode 1.32.0 --check (conformity PASS).

! plug
? events plug
# Receiver capability field: rev 1.1, HBR, 4 lanes + enhanced framing, 0.5 % downspread,
# 8b/10b, local EDID present.
> nr 000 16
< ack 16 11 0a 84 01 00 00 01 00 02 00 00 00 00 00 00 00
# Sink count 1, no service IRQ.
> nr 200 2
< ack 2 01 00
# No extended receiver capability field below DPCD 1.4; no MST.
> nr 2200 16
< ack 16 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00
> nr 021 1
< ack 1 00
> nw 600 01
< ack 1
# DDC ping: the library asks for an I2C read of size 0 without MOT; the NV0073 encoding
# (size minus one, bAddrOnly only for writes) turns that into a 1-byte read.
> ir 50 1
< ack 1 00
# An absent device (0x51, the second DDC address the library pings) NACKs the address.
> ir 51 1
< i2c-nack 0
